Detailed Instructions
  1. 1Download the file by tapping the "three dots" to the right of the file and selecting "Download". It is important that you do not open the file directly in Google Drive.
  2. 2Open your "Files" app, go to the "Downloads" folder, and locate the file you just downloaded. It will have the same name as it did in Google Drive.
  3. 3Tap the file. If an Open With prompt appears, select "Chrome" and then choose "Always". From now on, you should be able to just tap the file to open it automatically.
  4. 4Confirm that the file opened in Chrome. If it did, you are all set.
  5. 5If the option to always open with Chrome did not appear, or if the file still will not open in Chrome, follow these steps to reset your settings and try again:
    Go to "Settings" → tap "Apps" → select "Choose default apps" → tap "Opening links" → select "Chrome" (or "Chrome Beta") → tap "Clear" in the Clear defaults section.
